# Validation record

The raw executable evidence is included in `artifacts/`. Do not confuse source
implementation, a unit test, a browser test and independent CAD validation.

## Executed

`npm test`: 86 passing Node tests. Exact output is `artifacts/node-tests.log`.
These include kernel numerics, NURBS, expressions and cycles, constraint solving
and rollback, history, spatial queries/updates, routing, document independence,
DXF readers/writers, metadata identity, byte preservation, normalized-export
warnings, scene buffers, partial edits and topology-change rebuild decisions.

`python tests/browser_workflows.py`: 29 passing checks and no uncaught JavaScript
errors. The test uses the actual bundled standalone HTML, pointer/mouse actions,
mobile taps and a Chromium CDP two-touch pinch. The JSON report identifies its
storage adapter and actual rendering backend. It does not pretend that a
requested WebGPU backend was exercised when Canvas was used instead.

`python tests/browser_smoke.py`: desktop and mobile screenshots, layout/overflow
checks and backend-request diagnostics. All requested backend modes fell back
to Canvas 2D in the delivery environment. The WebGL/WebGPU-named screenshots
represent requested modes, not successful GPU validation.

`python tests/audit_dxf.py`: three example DXFs are independently opened and
audited with ezdxf 1.4.4. There are zero errors and zero repairs in the recorded
report. The input examples are generated by Conduit; the auditor is independent.

`npm run benchmark`: deterministic synthetic scene sizes of 1,000 / 10,000 /
100,000 line entities, 1,000 BVH queries, one-entity incremental edits, 10,000-line
DXF read/write and 100 obstacle routes. `artifacts/benchmark.json` records the
host and raw CPU wall times. It is a microbenchmark, not an interactive render
FPS test. Cold/JIT/GC effects and other workloads affect results.

The TypeScript consumer fixture `tests/types-smoke.ts` passes strict compile-only
validation with TypeScript 5.8.3 (`tsc -p tests/tsconfig.json`). No compiler is a
runtime/build dependency. Hand-authored and inferred declarations are provided.

All 13 npm tarballs were installed together into a clean temporary consumer with
`npm install --offline --ignore-scripts --no-audit --no-fund`. Every package could
be imported; a native-symbol DXF round trip and scene compilation passed using
only the installed archives. See `artifacts/npm-install-consumer.log`.

The complete source ZIP was extracted into a clean temporary directory, bootstrapped
without the original workspace dependencies, and tested. All 86 Node tests passed;
the source build reproduced the supplied standalone HTML byte-for-byte. See
`artifacts/clean-source-validation.log`.

## Environment limitations

The container's Chromium policy blocks navigation to URLs. Tests therefore load
the local standalone HTML with Playwright `set_content` rather than modifying
browser policy. The resulting opaque origin exposes no WebGPU API; WebGL2 is
also unavailable in this runner. No policy or security restriction was removed.

Browser persistence is replaced with a test-only memory adapter in the integrated
workflow suite. That adapter is not part of the shipped application. GPU driver
execution, IndexedDB durability, service-worker caching/installation, actual
file downloads and hardware device-loss recovery are not covered by those checks.

## Hardware acceptance gates still open

Run the served app on secure localhost/HTTPS with an actual GPU backend and
record the active renderer. Exercise device loss, shader compilation diagnostics,
100k+ geometry, same-topology range updates, resized canvases, precision at large
coordinates, zoom changes and GPU/Canvas visual comparisons. Record CPU submission
and genuine GPU timing separately; do not report CPU wall time as GPU duration.

Check iPhone/iPad Safari, Android Chrome, a Windows pen device and desktop browsers:
portrait/landscape transitions, pinch while editing, pointer cancel, palm input,
long-press/scroll arbitration, touch hit targets, keyboard appearance, safe areas,
file open/export and persistence after force-quit. Test storage quota failure and
explicit export backups. No real-device certification is asserted by this release.

## Reproduce

```sh
node scripts/bootstrap.mjs
npm test
npm run build
npm run benchmark

# Optional Python test tools are separate from the app's dependency-free build.
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/browser_smoke.py
python tests/browser_workflows.py
python tests/audit_dxf.py
```

Set `CHROMIUM_EXECUTABLE` to use an existing Chromium installation. Engine and
package tests do not need Python, browsers, network access or a GPU.
