# Explicit next engineering boundaries

This is a prioritized continuation plan, not a claim that these items are done.

## Production trust first

Validate WebGPU and WebGL2 on hardware, add image comparisons and device-loss
regression tests, verify actual mobile/pen behavior, storage quota recovery,
service-worker/offline flows and downloaded exchange files. Expand the independent
DXF corpus beyond self-generated examples. Fuzz parser and project-model inputs.

## CAD interoperability

Extend projected OCS into complete UCS/grip editing, exact per-entity conservative bounds, complete
text/style/font handling, comprehensive dimension styles and associativity,
all polyline join/cap variants, associative/gradient hatches, full complex SHX/text linetypes, layouts/viewports
and plotting, XREF/underlay resources and unknown-object preservation strategies.
Build explicit round-trip contracts before expanding entities. DWG and 3D solid
modeling require separate, deliberately licensed/implemented subsystems.

## High-density editing

Replace snapshot history with entity-delta transactions, index the authoritative
document by ID, make routing dependency-driven, cache symbol occurrences and move
block instancing to the GPU. Add progressive/streaming import, incremental scene
allocation for topology changes, GPU picking, text atlases, out-of-core storage
and measured hardware frame budgets. Retain numerical accuracy and diagnostics.

## Diagram intelligence and parametric CAD

Add connector crossing/line-jump handling, shared trunks, junction connectivity,
port classes/capacities, bus wiring, typed equipment properties, validated project
libraries and configurable symbol standards. Extend the solver with structural
rank/DOF reports, persistent constraint glyphs and larger sparse sketches. Add
robust polygon Boolean/topological operations and non-destructive feature history.

## Product UX and reusable UI

Add a complete recent-files/archives manager, multiple open documents, richer
attribute tables/BOM editing, command discovery, customizable shortcuts, selection
filters and better touch grip choice at high density. Isolate workbench CSS,
keyboard scopes and modal ownership for multiple embedded instances. Improve
strict public typing, automated package release/semver checks and framework adapters.
